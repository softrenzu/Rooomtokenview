# Rooom Token View

ChatGPT と Claude の個人プラン使用量を、Chrome / Edge の拡張アイコンからすぐ確認するための軽量ブラウザ拡張です。

## 何が見えるか

- ChatGPT: 直近の送信数、参考上限に対する残り件数・残り率、画面上に表示されたリセット情報
- Claude: Settings > Usage に表示される 5 時間セッションの残り率、週間残り率、リセット情報
- 拡張アイコンのバッジ: ChatGPT / Claude のうち少ない方の残り率

## なぜ「残りトークン」ではなく「残り使用量」なのか

ChatGPT Plus / Pro と Claude Pro / Max の個人向けサブスクリプションは、APIのような固定トークン残高ではありません。制限はメッセージ数、セッション、週次利用量、モデル、会話長、機能などで決まります。

そのため本拡張は次の方針です。

- Claude は公式の Usage 画面に表示された割合を読み取ります。
- ChatGPT は公式画面に残量が表示された場合はその情報を拾い、それ以外はブラウザ内で送信数を記録して参考上限から残りを推定します。
- ChatGPT の参考上限は設定画面から変更できます。初期値は 160 件 / 3 時間です。

## インストール

1. このリポジトリをダウンロードまたは clone します。
2. Chrome で `chrome://extensions`、Edge で `edge://extensions` を開きます。
3. 「デベロッパーモード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」を押します。
5. このリポジトリのルートフォルダを選択します。
6. Rooom Token View をツールバーに固定します。

## Claude の同期

拡張ポップアップの「同期」を押すと、`https://claude.ai/settings/usage` を非アクティブタブで開き、ログイン済みのブラウザ上に表示された Usage を読み取ります。取得後は同期用タブを閉じます。

Claude 側の画面構成が変わった場合、パーサーの更新が必要になることがあります。

## ChatGPT の精度について

ChatGPT の個人プランには、固定トークン残高を返す公開APIはありません。またプランやモデルによって上限が変わるため、ChatGPT の表示は「残り目安」です。

この拡張は ChatGPT 上で送信操作をローカル記録します。拡張導入前の送信履歴や、別ブラウザ・スマートフォンからの利用は自動では反映されません。

## プライバシー

- API キー不要
- ChatGPT / Claude のパスワードを取得しません
- 認証 Cookie を外部へ送信しません
- 会話本文を外部へ送信しません
- 計測値は `chrome.storage.local` に保存します
- 外部サーバーは使用しません

## 開発

依存パッケージなしで動作します。パーサーの簡易テストのみ Node.js を使用します。

```bash
npm test
```

## 現在の制約

- ChatGPT の正確な残トークン数は表示できません。そもそも個人プランが固定トークン制ではないためです。
- Claude の Usage UI が変更されると、読み取りルールの調整が必要な場合があります。
- ChatGPT を複数端末で使う場合、ローカル送信カウンターは端末間同期しません。
